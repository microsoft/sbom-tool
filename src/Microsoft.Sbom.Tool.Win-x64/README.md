# Microsoft SBOM Tool for win-x64

This package contains the self-contained Windows x64 executable for
[Microsoft SBOM Tool](https://github.com/microsoft/sbom-tool).

The executable is installed at:

```text
tools/win-x64/sbom-tool-win-x64.exe
```

See the [Microsoft SBOM Tool documentation](https://github.com/microsoft/sbom-tool#readme)
for command-line usage.
